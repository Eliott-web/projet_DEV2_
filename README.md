# projet_DEV2_

⚠️⚠️ Entre le début du projet et aujourd'hui, Python 3.14 est sorti :
Malheureusement, une de nos dépendances est incompatible avec cette version. Assurez-vous donc d'être en Python 3.13 ou 3.12. Désolé pour cette étape d'installation supplémentaire. ⚠️⚠️

Bien le bonjour ! Dans ce jeu de plateau farfelu, le but est d'atteindre la dernière case.

Pour lancer le jeu en mode console, il vous suffit d'exécuter le fichier mainconsole.py.

Pour le lancer en mode interface graphique, exécutez maingui.py.

⚠️ Attention : il y a des modules à installer. Il vous suffit de consulter le fichier requirements.txt. Bon jeu !
